<task type="auto">
  <name>Task 2: Build the wave module, ocean shader, sky/fog, SceneRoot, and dev sandbox route</name>
  <files>client/src/scene/waves.ts, client/src/scene/Ocean.tsx, client/src/scene/SkyDome.tsx, client/src/scene/SceneRoot.tsx, client/src/dev/SceneSandbox.tsx, client/src/main.tsx</files>
  <action>
- `scene/waves.ts`: export a `WaveParams` type (`dirX`, `dirZ`, `steepness`, `wavelength`) and a small fixed array of 2-3 layered wave constants, plus a pure `gerstnerHeight(x: number, z: number, time: number, waves: WaveParams[]): number` function implementing the standard Gerstner formula (04-RESEARCH.md Pattern 1 / Code Examples). This is the SINGLE source of truth for wave math — 04-02's ship bob and Ocean's shader both read from these exact constants, never a re-derived approximation.
- `scene/Ocean.tsx`: a `<mesh>` with a subdivided `THREE.PlaneGeometry` (~200x200 segments) and a `THREE.ShaderMaterial` built once via `useMemo`. Vertex shader displaces `position.y` using the Gerstner formula with uniforms mirroring `waves.ts`'s constants; fragment shader renders a stylized holographic teal/blue gradient with Fresnel rim brightening (NOT a mirror-reflection surface — 04-RESEARCH.md explicitly rules out `three`'s reflection-based `Water.js` addon here for cost and aesthetic-fit reasons). Mutate `uniforms.uTime.value` inside `useFrame`; never drive it through React state (would re-render every frame).
- `scene/SkyDome.tsx`: drei's `<Sky>` component (tunable `sunPosition`/`turbidity`) plus a `<fog attach="fog">` for the time-of-day gradient PROJECT.md describes. Add one `<ambientLight>` + one `<directionalLight>` positioned to match the sun.
- `scene/SceneRoot.tsx`: a `<Canvas>` wrapping `<Ocean />`, `<SkyDome />`, and drei's `<PerformanceMonitor>` plus a dev-only `<Stats />` (gate on `import.meta.env.DEV`) so FPS/draw-calls are visible immediately — this is the phase's required performance baseline.
- `dev/SceneSandbox.tsx`: a standalone full-viewport page rendering `<SceneRoot />`. This exists ONLY for isolated visual verification across 04-01 through 04-05; plan 04-06 removes it once the scene is wired into the real screens.
- `main.tsx`: if `new URLSearchParams(window.location.search).get("dev") === "scene"`, render `<SceneSandbox />` instead of `<App />`. This is the ONLY change to the existing app's entry point — `App.tsx` and the entire multiplayer flow (lobby/placement/battle/postgame) must render exactly as before when the query param is absent.
  </action>
