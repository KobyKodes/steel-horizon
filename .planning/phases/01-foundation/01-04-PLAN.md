<feature>
  <name>Shot resolution and win detection</name>
  <files>shared/src/shots.ts, shared/src/shots.test.ts</files>
  <behavior>
    Pure functions over a defender's fleet and shot history — no mutable game object (the server composes state in Phase 2; keeping this stateless makes it trivially testable and snapshot-friendly).

    `resolveShot(fleet: FleetPlacement, previousShots: Coordinate[], target: Coordinate): ShotOutcome` where ShotOutcome is
    { ok: true; result: "miss" } | { ok: true; result: "hit"; ship: ShipClassId } | { ok: true; result: "sunk"; ship: ShipClassId } | { ok: false; error: "OUT_OF_BOUNDS" | "CELL_ALREADY_SHOT" }.
    Error codes reuse the ErrorCode values from protocol.ts.

    Cases (fixture: one known valid fleet used across tests):
    - Shot at open water → miss
    - Shot on a ship cell with other cells of that ship intact → hit, names the ship
    - Shot completing a ship (all its cells now shot) → sunk, names the ship — NOT hit
    - One-shot kill scenario: destroyer (length 2) with one prior hit, second cell → sunk (never reports plain hit on a completing shot)
    - Repeat of a previous shot (hit or miss alike) → { ok: false, error: "CELL_ALREADY_SHOT" }
    - Target out of bounds (col 10, row -1) → { ok: false, error: "OUT_OF_BOUNDS" }
    - The target itself is NOT in previousShots when resolving (caller appends after; test documents this contract)

    `isFleetDestroyed(fleet: FleetPlacement, shots: Coordinate[]): boolean`
    - All 17 ship cells shot (extra misses interleaved) → true
    - 16 of 17 ship cells shot → false
    - Empty shot list → false
    - Shots covering every ship cell plus repeats/misses → still true (idempotent w.r.t. duplicates)
  </behavior>
  <implementation>
    Replace the `export {};` placeholder in shots.ts (created by 01-02 — do not create new files, do not touch index.ts; the barrel already re-exports this module). Build on cellsForPlacement from fleet.ts and inBounds/coordsEqual from board.ts — do NOT re-derive cell expansion. resolveShot: bounds-check, repeat-check against previousShots, then find the ship (if any) whose cells contain target; if hit, it is "sunk" iff every other cell of that ship is in previousShots. isFleetDestroyed: every cell of every placement appears in shots (Set of "col,row" keys for O(1) lookups). Assume fleet is already valid — validation is 01-03's job and the server validates at placement time; do not duplicate it here.
  </implementation>
</feature>
