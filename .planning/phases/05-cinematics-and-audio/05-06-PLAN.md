<task type="auto">
  <name>Task 1: Build AudioManager with synthesized SFX and a master mute bus</name>
  <files>client/src/audio/AudioManager.ts</files>
  <action>
Create a singleton `AudioManager` module wrapping a single `AudioContext`, per 05-RESEARCH.md's "Don't Hand-Roll" guidance: one `GainNode` as a master bus that every sound connects through, so mute is a single `gain.value = 0` toggle rather than per-sound tracking. Export functions:
```typescript
export function playFire(): void;      // firing report — short percussive click/thump synthesized from filtered noise + a quick pitch-dropping oscillator
export function playSplash(): void;    // per 05-RESEARCH.md's verified example: filtered noise burst with a fast exponential decay envelope
export function playExplosion(): void; // low oscillator + noise burst with a longer envelope; if pure synthesis sounds thin, embed one small compressed sample (base64-encoded, a few KB, inlined as a data URI or bundled asset — still "self-contained," no network fetch) and play it via AudioBufferSourceNode instead — decide by ear during implementation per 05-RESEARCH.md's Open Question 1, don't over-invest in synthesis if a tiny sample sounds clearly better
export function playKlaxon(): void;    // on ship sunk — a repeating short square/sawtooth oscillator pulse, classic alarm character
export function startAmbientLoop(): void;  // continuous low ocean/wind ambience, started once (e.g., on first user interaction, since browsers block audio autoplay before a gesture)
export function stopAmbientLoop(): void;
export function setMuted(muted: boolean): void;   // sets the master GainNode to 0 or 1, persists to localStorage
export function isMuted(): boolean;    // reads persisted state, defaulting to unmuted
```
All sound-producing functions must be no-ops (or at minimum silent) if `isMuted()` is true — enforced structurally by routing everything through the master GainNode rather than checking mute state in every function individually. `AudioContext` must be created lazily (on first call, not at module load) since browsers require a user gesture before audio can start — do not attempt to autoplay `startAmbientLoop` before any interaction has occurred.
